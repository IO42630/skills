# The 3 As of Cybersecurity

- The 3 As are the pillars of identity and access control.
    - Authentication: verify identity.
    - Authorization: grant permissions.
    - Accounting: record activity.
- Each answers a different question.
    - Authentication asks "Who are you?"
    - Authorization asks "What may you do?"
    - Accounting asks "What did you do?"
- Together they form the AAA framework.

## 1. Authentication

- Proves a user or system is who it claims to be.
- Runs before any access is granted.
- Evidence comes from authentication factors.
    - Something you know: password, PIN, security answer.
    - Something you have: hardware token, phone, smart card.
    - Something you are: fingerprint, face, iris.
- Multi-factor authentication requires two or more factor types.
- Common weaknesses:
    - Reused or weak passwords.
    - Phishing that harvests credentials.
    - Poor patching that leaks secrets.

## 2. Authorization

- Determines what an authenticated identity may do.
- Runs only after authentication succeeds.
- Enforced through access control models.
    - RBAC: access follows roles.
    - ABAC: access follows attributes and policies.
    - MAC: access follows system-assigned labels.
- Least privilege grants the minimum access needed to work.
- Common failures:
    - Overly broad roles.
    - Stale permissions for former staff.
    - Missing checks on server-side endpoints.

## 3. Accounting (Auditing)

- Records what happened, who did it, and when.
- Also called auditing when the focus is review.
- Provides evidence and non-repudiation.
- Core components:
    - Logs for logins, access, and changes.
    - Audit trails linked to identities.
    - Monitoring that alerts on anomalies.
- Supports incident response, forensics, and compliance.

## How the 3 As Work Together

- Authentication without authorization leaves access unconstrained.
- Authorization without authentication protects nothing.
- Accounting without the other two cannot attribute actions.
- Strong access security needs all three in sequence.

## Common Confusions

- The CIA triad is Confidentiality, Integrity, Availability.
    - It describes data properties, not identity steps.
- Some frameworks split accounting from auditing.
- Some add non-repudiation as a fifth A.
- Zero trust applies the AAA checks on every request.
